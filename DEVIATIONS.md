# Deviations from NetHack

Every intentional rule difference from NetHack is logged here.

| Area                                   | NetHack behavior                                                                                                                                                                  | Our behavior                                                                                                                                                                                                 | Reason                                                                                                    |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| RNG                                    | `rn2(x)` uses `RND() % x` (modulo bias)                                                                                                                                           | Rejection sampling, no modulo bias                                                                                                                                                                           | Uniform distribution; outcome sequences differ anyway (ref: src/rnd.c)                                    |
| Level generation                       | Locked doors and trapped doors (and door mimics)                                                                                                                                  | Locked doors are closed doors; no trapped doors or mimics                                                                                                                                                    | Kick/unlock/traps are not implemented in M1 (ref: src/mklev.c dosdoor)                                    |
| Level generation                       | Boulders in blocked extra corridors                                                                                                                                               | No boulders; their rn2(50) roll is skipped                                                                                                                                                                   | Objects are not implemented (ref: src/sp_lev.c dig_corridor)                                              |
| Level generation                       | MAXNROFROOMS is 40; MAXRECT is COLNO*ROWNO/30                                                                                                                                     | Room cap is `max(40, floor(40 * w*h / (80*21)))`; the rect cap already scaled with area                                                                                                                      | Large maps would otherwise stop at 40 rooms (ref: include/global.h, src/rect.c init_rect)                 |
| Level generation                       | dig_corridor gives up after 500 steps                                                                                                                                             | Cap is `max(500, 2*(w+h))`                                                                                                                                                                                   | 500 is too short for forced joins on very large maps (ref: src/sp_lev.c dig_corridor)                     |
| Level generation                       | Vaults, niches, themed rooms, subrooms, special rooms are made; stairs depend on dungeon level (no upstairs on level 1)                                                           | Only ordinary rooms and corridors; both staircases always exist (up in another room when possible, else a different cell of the same room)                                                                   | Not needed for M1 (ref: src/mklev.c makelevel, generate_stairs)                                           |
| Level generation                       | Rooms may end up disconnected (failed forced joins)                                                                                                                               | After makecorridors, any stray room is joined by a deterministic breadth-first corridor with plain doorways (no RNG)                                                                                         | Guarantees the "all rooms connected" invariant (ref: src/mklev.c makecorridors)                           |
| Level generation                       | Map is 79 usable columns (x = 0 unused), min size undefined                                                                                                                       | 0-based coordinates; internally x+1 is used so placement matches NetHack; minimum size 10x10 (smaller never places a room: create_room needs a 9-row free rectangle)                                         | Any size must work; NetHack's rect.c limits make smaller maps impossible                                  |
| Vision                                 | `clear_path()` Bresenham-style line-of-sight tables                                                                                                                               | Symmetric recursive shadowcasting; seen iff in LOS and (lit or adjacent)                                                                                                                                     | Symmetric, artifact-free, fast on large maps (ref: src/vision.c vision_recalc())                          |
| Vision                                 | Doors/walls at the end of a dark corridor are hidden unless an adjacent cell is lit                                                                                               | Not ported; lit-or-adjacent rule only                                                                                                                                                                        | Simplification for M1; revisit with vision polish (ref: src/vision.c)                                     |
| Doors                                  | Opening a door can fail ("This door is stuck") based on `rnl(20)` vs Str/Dex/Con                                                                                                  | Auto-open always succeeds                                                                                                                                                                                    | Attributes don't exist yet (ref: src/lock.c doopen_indir())                                               |
| Hero | Starting kit: Valkyrie[] items, the dagger becomes the alternate weapon, food ration quantity can be 2 from mksobj | Real objects (+1 spear wielded, dagger, +3 small shield worn, food ration); no alternate-weapon slot, so the dagger is just carried; the ration is always 1 | No secondary weapon slot; fixed quantity keeps the kit predictable (ref: src/u_init.c ini_inv) |
| Armor delay | `oc_delay` turns pass before the armor takes effect: AC and `known` change when `Armor_on` runs | The armor is worn and AC changes at once; the hero is then helpless for `oc_delay` turns (monsters act) with the same finishing message | Simpler state; the time cost is the same (ref: src/do_wear.c accessory_or_armor_on, Armor_on) |
| Pick up | Autopickup per options; `pile_limit` option; menus ordered by class; `pickup_burden` option; scare monster / cockatrice corpse checks | Autopickup is off (NetHack 5.0 default); `pile_limit` 5 and `pickup_burden` Stressed are fixed; menu lists the pile top first; no special-object checks; arriving by stairs prints no 'You see here' | Options and special objects are not implemented (ref: src/pickup.c pickup, lift_object, src/invent.c look_here) |
| Inventory display | Gold is `$` in the inventory; discoveries list in order of discovery with the bare description ('puce') | Gold is `$`; discoveries list in object-list order with the full appearance phrase ('puce potion', 'scroll labeled FOO') | Appearance names are whole phrases in the catalog (ref: src/o_init.c dodiscovered) |
| Wielding | Any item can be wielded; `x` swaps primary and alternate weapons; quiver | Only weapon-class items are offered; no alternate weapon or quiver; 'Wield nothing' is not offered once the wielded weapon is known to be cursed | Alternate weapon and quiver arrive with throwing (ref: src/wield.c dowield) |
| Search                                 | `dosearch0()` uses `rnl(7 - fund)` with Luck, lenses/artifact bonus, and also finds hidden monsters and traps                                                                     | Secret doors and corridors only, with Luck 0 and no bonus; a found secret door always becomes a closed door                                                                                                  | Luck, items, hidden monsters and traps do not exist yet (ref: src/detect.c dosearch0())                   |
| Travel                                 | `findtravelpath()` falls back to guess mode (walks to the reachable cell nearest an unreachable target); `_` also offers `<` `>` shortcuts                                        | Unreachable/unknown targets are not offered and performing one costs no time; the path is re-planned every step over remembered map via `query.pathTo`                                                       | Simplification for M2 (ref: src/hack.c findtravelpath(), packages/content/src/travel.ts)                  |
| Travel | `lookaround()` also stops for fountains etc.; `context.travel1` first-step quirks | Travel stops on any cell with objects (via `check_here()`), and for hostile adjacent monsters; no other features or first-step quirks | Only objects exist (ref: src/hack.c lookaround, src/pickup.c check_here) |
| Melee combat: Luck, rings, traps | Luck adjusts the to-hit roll, rings add to-hit/damage, traps subtract from to-hit | None of these exist; to-hit uses Str/Dex, level, AC (worn armor), encumbrance, wielded weapon enchantment/hit bonus and skill | Systems arrive later (ref: src/uhitm.c find_roll_to_hit) |
| Weapon skills | Skills train with use, `#enhance` raises them, role skill maximums apply | Skill levels are set once at start (Skill_V: kit weapons Basic, other role skills Unskilled, rest Restricted) and never change; no training or `#enhance`; no martial arts, two-weapon or riding | No skill system yet (ref: src/weapon.c skill_init, weapon_hit_bonus, weapon_dam_bonus) |
| Hero attack extras                     | Knockback on 1/6 of weapon hits, flee-on-low-HP chance, peaceful confirmation prompt, passive attacks, thick-skinned damage nullification, fleeing/stunned/trapped target bonuses | Not implemented; attacking a peaceful just makes it hostile, no prompt                                                                                                                                       | Out of scope for M2 (ref: src/uhitm.c mhitm_knockback, attack_checks, known_hitum)                        |
| Monster weapon attacks                 | AT_WEAP uses the wielded weapon's dmgval and hitval, or plain dice if unarmed                                                                                                     | Always plain `d(n,d)`; monsters carry no objects. Hug, engulf, gaze, spit, breath, explode and magic attacks are skipped; extra damage for undead at midnight and monster knockback are not applied          | No objects or special damage types in M2 (ref: src/mhitu.c mattacku, hitmu)                               |
| Kills                                  | A kill leaves a corpse and possibly death drops                                                                                                                                   | The monster just disappears; experience is still awarded                                                                                                                                                     | No items until M3 (ref: src/mon.c xkilled)                                                                |
| Monster AI                             | `dochug()` also handles fleeing, scared monsters (Elbereth), confusion, invisibility, spellcasting, defensive/misc item use, weapon wielding, per-monster specials                | None of these: monsters hunt or wander (peaceful, 1/3 of bats), attack adjacent hostiles, and do nothing else                                                                                                | No items or status effects yet (ref: src/monmove.c dochug(), m_move())                                    |
| Monster AI                             | `m_move()` follows the hero's trail when out of sight (`gettrack`), picks up items, avoids traps and boulders, shortsighted levels, monsters can displace/fight each other        | Monsters always head for the hero's true position (as `set_apparxy` does); no trail, items, traps, boulders or monster-vs-monster fights; `mtrack` is kept in `modData.nh.mtrack`                            | Hero trail and objects do not exist yet (ref: src/monmove.c m_move(), set_apparxy())                      |
| Monster AI                             | `distfleeck()` rolls `rn2(5)` (bravegremlin) on every call; `mfndpos()` also checks water, lava, NODIAG, long worms, weight for diagonal squeezes                                 | These rolls and checks are skipped; only monsters of size large or bigger fail tight diagonal squeezes                                                                                                       | Not applicable to the roster (ref: src/monmove.c distfleeck(), src/mon.c mfndpos())                       |
| Monster doors                          | Locked doors stop monsters without a key; doors can be trapped; monsters seen opening a door get `Monnam opens a door` (or "You see a door open" when unseen but in sight)        | Locked doors are plain closed doors, so any monster with hands that is not tiny opens them; message is "The X opens a door." when the door square is visible, else "You hear a door open."                   | Locked/trapped doors not generated (ref: src/monmove.c postmov())                                         |
| Monster waking                         | `disturb()` checks the hero's real Stealth                                                                                                                                        | Stealth is assumed from Valkyrie experience level 3 (ref: val_abil[]); no Aggravate Monster, ettin, nymph, jabberwock or leprechaun cases                                                                    | Only the stub Valkyrie exists (ref: src/monmove.c disturb())                                              |
| Monster generation                     | `peace_minded()` uses the hero's alignment type and record, minions, the Amulet, quest monsters                                                                                   | Hero is neutral with record 0 forever; race rules: gnomes and orcs always hostile (human hero)                                                                                                               | No alignment system yet (ref: src/makemon.c peace_minded())                                               |
| Monster generation                     | `makemon()` sets gender, inventory/weapons (`m_initweap`, `m_initinv`), special-class setup, shapechangers, `mvitals` birth limits; `enexto()` uses `collect_coords`              | None of these; `enexto()` is a ring search (Chebyshev radius, random order within a ring); alignment shift of `rndmonst` is 0 (Dungeons of Doom are unaligned); `makemon_rnd_goodpos` uses x in [1, width-3] | No items or genders yet (ref: src/makemon.c makemon(), rndmonst_adj(), src/teleport.c enexto_core())      |
| Monster generation                     | Level monsters are placed in 1/3 of ordinary rooms (`fill_ordinary_room`), plus special rooms, traps and mimics                                                                   | Only the 1/3-per-room monster; the spawn rate is always 1/70 per turn (no Castle/demigod rates)                                                                                                              | Only ordinary rooms exist (ref: src/mklev.c fill_ordinary_room(), src/allmain.c maybe_generate_rnd_mon()) |
